# Utilities

General-purpose utility scripts for common tasks.

## Available Scripts

- `file_organizer.py` - Organize files in a directory by their extensions
- `backup.py` - Create timestamped backups of files or directories

## Usage

Each script includes help documentation. Run with `-h` or `--help` flag for details:

```bash
python file_organizer.py --help
python backup.py --help
```
